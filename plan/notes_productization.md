# Notes: 聊天记录导出器产品化

## Confirmed Requirements

### 导出内容
- “聊天正文与图片”本身也是一个可勾选导出分组。
- 6 类隐藏/半隐藏上下文全部支持勾选导出。
- 每类内容在 UI 中显示为“中文标签（原始字段名）”。
- 每类内容都要带说明，解释其作用和是否通常客户端不可见。
- 正文支持可选消息时间戳。
- 正文支持按日期范围 / 时间区间裁切导出。

### 导出模式
- 内置 3 个默认模式：
  - 阅读版
  - 审计版
  - 取证版
- 允许用户新建自定义模式并保存。

### 导出组织方式
- 每条会话固定导出到一个独立文件夹。
- 会话文件夹内支持单文档导出。
- 会话文件夹内支持多文档导出。
- 支持隐藏内容与聊天正文：
  - 混排在一个文档
  - 作为附录
  - 拆为单独文档
- 支持用户自选导出结果根目录。

### 会话选择
- 支持导出单条会话。
- 支持导出多条会话。
- 支持从列表中勾选多个会话。

## Product Direction
- 首期：共享核心 + VS Code 插件。
- 二期：Codex 插件接入同一核心。
- 三期：如有需要，再补独立 exe 打包形态。

## Verified Context
- 当前已验证会话主数据源为本地 `C:\Users\20312\.codex\sessions`。
- 基于当前本机证据，推断 VS Code Remote-SSH 场景仍可由本地 VS Code 插件完成导出入口。
- Codex 插件不是功能上必须，但能提供更顺手的客户端内入口。
